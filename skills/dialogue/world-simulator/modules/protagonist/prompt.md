# 主角设定

> 技能文档。程序只切割下方 **fence 块**。  
> 产物外壳：`docs/context-fragment-design.md`。  
> 落盘后挂在当前选用的用户角色卡下（横线下方），不进全局列表。关掉这局就不加载。不改其它技能正文。

## meta

```meta
name: 主角设定
id: protagonist
artifact: 设计.主角设定
declaration: >
  钉清 @玩家 扮演的那个人：名字、背景、特殊设定（身份/金手指等）。落盘后挂在当前选用的用户角色卡下。
when: |
  用户代入，且这局角色有名字、身份或金手指（快穿短局几乎总有一张脸），尚无「设计.主角设定」定稿。
when_not: |
  旁观或把角色当棋子、不要代入身份 → 不排。
  只要体验感觉、不要名片 → 「美学纲领与交互范式」。
  NPC 名片 → 「具体实例」。开场第一拍 → 「开场白与开场变量」。
boundary: |
  本技能：@玩家 扮演的那一张名片（名字、背景、特殊设定）。
  美学纲领与交互范式：体验与轮转——本步不重定。
  实现机制：世界法则——金手指写在本步「它能做什么」，法则来源不写。
  开场白：第一屏怎么开始——本步不定时间地点冲突。
feeds: gm
```

## opening

```opening
这局你代入谁？（想到什么写什么）

1. 名字：别人怎么叫你？不要写 @玩家。
2. 背景：一两句来历或处境即可，不写世界百科。
3. 特殊设定：身份、金手指、随身之物；没有就说没有。
```

## task

```task
把用户原话收成 @玩家 扮演的那一张名片，写入 tag「设计.主角设定」。作用对象是本局黑板；程序读取后挂在当前选用的用户角色卡下，不写进全局列表。

产物必须是 **context-fragment.v1** JSON。正文只含：名字、背景、特殊设定（身份 / 金手指 / 其它）。须含 schema / 技能 / brief；mount 主世界层；稳变多为 stable。

名字：本局称呼，进游玩替换 @玩家。禁止写成「@玩家」「用户」「主角」。缺名字 → 追问 1 题，不交半张卡。
背景：一两句。没有就写「未定」，不编百科。
特殊设定：有则写身份、金手指（能做什么、限制一句）、其它；没有就各写「无」。

一次对话、一次验收。不写世界、不写文风、不写开场第一拍。
```

## principles

```principles
1. 一张脸：删掉仍知道「我是谁」的句子才落盘。
2. 金手指写能力与限制，不写它为何存在。
3. 材料不够：名字必须问出；背景和特殊设定可「未定」或「无」。
4. 规格走 JSON；追问一次 1 题。
```

## probe

```probe
只追问挡住成卡的缺口。缺名字：给 2 个称呼选项 + 其它。背景/金手指用户说没有 → 写「无」，不问第三轮。
```

## output

```output
{
  "schema": "context-fragment.v1",
  "技能": "主角设定",
  "brief": "一句话：谁、带着什么特殊",
  "mount": ["world-simulator"],
  "稳变": "stable",
  "正文": {
    "名字": "林晚",
    "背景": "原剧情里被退婚的庶女，刚穿过来那天正被当众羞辱。",
    "特殊设定": {
      "身份": "侯府庶女 / 原女主的垫脚石",
      "金手指": "能看见别人对她的好感数字；别人看不见。",
      "其它": "无"
    }
  },
  "自评": {
    "维度": [
      { "名": "可代入", "分数": 8, "说明": "名字能替换 @玩家，身份清楚" },
      { "名": "够用", "分数": 8, "说明": "没有世界百科，特殊设定能约束正文" }
    ],
    "薄弱点": "一句话"
  },
  "追问": {
    "导语": "名片还缺：",
    "题目": []
  },
  "开放问题": []
}
```

硬规则：
1. 合法 JSON；必含 schema / 技能 / brief / 正文 / 自评 / 追问。
2. 正文是对象，键为 名字 / 背景 / 特殊设定；特殊设定为对象（身份、金手指、其它），不是一段散文。
3. 名字不是 @玩家 / 用户 / 主角。
4. 禁止写数字 order、禁止输出执行单元列表。
5. summary：`主角设定 · {名字}`。

## checklist

```checklist
- [ ] 含 schema / brief / 正文 / 自评 / 追问？
- [ ] 名字可替换 @玩家？不是占位词？
- [ ] 背景一两句或「未定」？特殊设定有则写能力与限制，无则「无」？
- [ ] 没有世界百科、没有开场第一拍？
```

## examples

```examples
好：名字「林晚」；背景一句穿来当日处境；金手指「看见好感数字」+限制「别人看不见」。
坏：名字写成 @玩家；把侯府地理、朝堂势力写进背景；把开场羞辱戏全文写进名片。
```
