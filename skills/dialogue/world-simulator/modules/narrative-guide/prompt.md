# 叙事指南

## meta

```meta
name: 叙事指南
id: narrative-guide
artifact: 设计.叙事指南
declaration: >
  从文风库写成遣词、视角执行、段落形态、笔墨落点和少量禁忌。
  体验句留在美学纲领，人称与描写权限留在故事推进与交互范式。
when: |
  已有美学纲领，但游玩正文还不知道怎么落笔：遣词、视角执行、笔墨落谁身上、场合是否换写法档、绝对不能写什么。
  用户主动谈文风、措辞、叙述声音、写法档时也使用。
when_not: |
  本技能只给对话落盘。工序编排不排本步（编排池是「叙事指南与故事推进」）。
  美学未钉 → 先「美学纲领」。
  用户明确说本局不用文风细则，且美学里已有可执行遣词方向 → 可不使用。
  只谈推进、输入用法、单轮字数 → 「故事推进与交互范式」。可见区域 → 「回复呈现」。版式 → 「正文组成」。
boundary: |
  本步只交怎么落笔：选用文风、遣词（叙述声音、视角执行、段落形态）、笔墨落点、少量绝对禁忌、有切换才写的写法档。
  体验内核、描写焦点、边界与尺度留在美学纲领，本步点名引用，不改写成第二份体验。
  人称、可写内心、输入用法、单轮字数归故事推进与交互范式。
feeds: narrator,gm
```

## opening

```opening
说说这局正文希望读起来像什么。可以直接点文风方向，或说不同场合要不要换一种写法。重点写“要怎么写”，只有真正碰不得的再提禁忌。
```

## task

```task
把本局落笔方法整理为叙事指南，写入 `设计.叙事指南`。先读美学的 `体验内核` 和 `描写焦点`，只把焦点里的对象或瞬间点进 `笔墨焦点.详写`；体验句本身不搬过来，也不换说法再写一遍。人称、可写内心以故事推进与交互范式的 `交互范式` 为准，本步在 `遣词.视角` 只写镜头距离和如何不漂人称。

再用 `read_library_entry` 从文风库读取最相关条目（默认 1～2；确需第三种时须写 reason 并标明适用场合）。`风格推荐` 和 `本局要求` 只写节奏、用词层级、句段形态、对话与叙述怎么配。写成台词、角色正在做的场面，或把某类人物当例子演一遍，就改回做法。

材料够就成稿。会改落笔的缺口进 `self_score.gap`。产物正文不含评分、诊断或追问。
```

## principles

```principles
1. 美学已经写了要什么感受。本步写怎么落笔。`详写` 点名对象或瞬间；一句若是体验内核的同义改写，删掉。`边界与尺度` 里真正碰不得的收成禁忌短句，用法本身留在美学，不整段抄来。
2. 文风库是参考：读完改成本局可执行的节奏和句段，记下适用场合。不搬库里的范文。
3. 优先 1～2 种文风。确需第三种时，每种都要有切换场合。
4. `风格推荐` 与 `写法要求` 写对象、节奏、注意力落点、句段形态。不写示范段，不写台词，不用「某类角色被怎样」代替做法。
5. 用户未提段落形态时，`遣词.写法要求` 写入「完整长自然段叙述，不要单句成段」；用户另定则按用户写。单轮字数归故事推进与交互范式。
6. `遣词.视角` 只写执行：镜头距离（贴身 / 中景 / 远观，何时拉近）；内心写到哪（只写交互范式允许写内心的一方，其余用外显言行）；如何不漂人称。交互范式未定视角时按美学站位取最贴的写法，并在 gap 写明。
7. `叙述者`、`代入取向` 能从站位推出、且和视角执行不是同一句时才写；否则省略。
8. 禁忌只留少数绝对不能写的短句。其余写成正向做法。
9. 写法档只在有切换时写。用户报的具体场合（如当众折辱、独处）升进某一档的适用场合与写法要求，不单列成桥段清单。
10. 推进、输入用法、单轮字数、版式不在本步写。
```

硬规则：
1. 输出合法 JSON。`选用文风` 默认 1～2 项，最多 3 项，每项有适用场合与本局要求。
2. `风格推荐`、`本局要求`、`写法要求`、`详写` 不写台词、不写角色正在做的场面、不把体验内核换个说法再写一遍。
3. 除 `禁忌` 外，正文以正向要求为主。
4. 用户未定段落形态时，`遣词.写法要求` 含「完整长自然段叙述，不要单句成段」。
5. `遣词.视角` 只执行交互范式里的人称与可写内心，不改范围。
6. `写法档` 无切换则整项省略。有则每档写场合与写法要求。
7. 产物正文不写自评、追问、推进、输入用法、单轮字数。
8. `mount` 固定包含 `narrator` 与 `world-simulator`。

## score

```score
遣词可执行：
- 5：风格推荐与写法要求具体到节奏和句段，能直接落笔；视角执行写清。
- 3：方向清楚，但仍有几处是氛围词，或视角含糊。
- 1：只有题材或情绪标签。

笔墨与禁忌：
- 5：详写点名对象或瞬间，没有把体验内核再写一遍；禁忌少而可执行。
- 3：落点大体有，但详写在复述感受，或禁忌偏多。
- 1：几乎不谈笔墨，或堆满否定句。

文风选用：
- 5：1～2（偶发 3）条贴合本局；多档时切换场合清楚。
- 3：选用相关，但场合区分弱。
- 1：未读库硬编，或多种文风无差别并列。

本局化：
- 5：库条目收成可执行的节奏和句段；体验句仍只在美学。
- 3：有微调，但仍有整段近乎库原文，或详写在改写体验内核。
- 1：照抄库条目，或本局要求写成台词和场面。
```

## checklist

```checklist
- [ ] 详写只点名对象或瞬间，没有改写体验内核？
- [ ] 已读取文风库，本局要求是节奏和句段？
- [ ] 选用文风 1～2（最多 3），各有适用场合？
- [ ] 风格推荐里没有台词、场面或角色举例？
- [ ] 视角只写执行，未改交互范式的人称与可写内心？
- [ ] 用户未定段落形态时已写长自然段默认？
- [ ] 未写入推进、输入用法、单轮字数或版式？
```

## examples

```examples
好：
- 描写焦点已是「让步或反抗的那一刻」→ 详写只写「让步与反抗」，不把体验内核再写一遍。
- 风格推荐：「短句、少形容词、对话压成一句」。本局要求同样只写节奏和句段。
- 视角：「第二人称贴身；只写你的内心；NPC 只写外显」。

缺料时：
- 文风库没有贴合条目 → gap 问一个方向，不编第三种文风充数。
- 交互范式未定人称 → 按美学站位先写一种执行，gap 标明。

偏了就改回：
- 风格推荐写成某角色的台词，或「骄横千金被按住后改口」→ 改成节奏、用词、句段。
- 详写把「反复感到掌控」再写一遍 → 删掉，只留焦点里的对象或瞬间。
- 禁忌把美学的边界与尺度整段抄来 → 只留真正碰不得的短句。
```
