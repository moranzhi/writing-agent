# 叙事指南

> 对话落盘技能。程序只切割下方 **fence 块**；`##` 标题仅供人读。  
> 产物外壳：`docs/context-fragment-design.md`。  
> 工序编排仍用「叙事指南与故事推进」；本步只钉怎么写，不钉故事怎么往前。

## meta

```meta
name: 叙事指南
id: narrative-guide
artifact: 设计.叙事指南
declaration: >
  美学已有方向时：把感觉落成可执行的遣词、笔墨落点、禁忌与写法档；不重做体验问卷，也不钉故事怎么往前
when: |
  已有美学纲领（或等价），但游玩正文仍不知道怎么写：遣词什么味道、笔墨落谁身上、场合换哪一档写法、绝对不能写什么。
  用户主动谈文风、措辞禁忌、写法档（官能/爽文/恐怖/情色等）也排。
  交互范式或故事推进已钉停笔/轮转，不构成不排本步的理由。
when_not: |
  本技能只给对话落盘。工序编排不排本步（编排池是「叙事指南与故事推进」）。
  美学未钉 → 先「美学纲领与交互范式」。
  用户只要感觉/站位、不要文风细则 → 不排，沿用美学。
  只谈故事怎么往前、用户输入用法 → 「故事推进」。
  版式/壳 → 「正文组成」；每轮看什么（字数/变量/日期）→ 「回复呈现」。
boundary: |
  本技能：一份 context-fragment，写清怎么写（遣词、笔墨、禁忌、写法档）。
  故事推进：怎么往前、输入用法——本步不定。
  美学：感觉与轮转。生成规则/变量*：合同与表。
feeds: narrator,gm
```

## opening

```opening
美学里的感觉已有方向时，请谈「正文怎么写」（想到什么写什么）：

1. 像什么文风？遣词什么味道？笔墨花在谁身上？有什么绝对不能写？
2. 正文若有几种写法档要切换（官能 / 爽文 / 恐怖 / 情色这类），点名即可；没有就说没有。
```

## task

```task
你正在执行「叙事指南」。产物必须是 **context-fragment.v1** JSON，写入「设计.叙事指南」。

把美学里的感觉落成可执行的写法。作用对象是本局游玩正文（转述与主世界层都读这份）。

执行顺序：
1. 若提示中有【文风库 · 可选用】且用户点名/对上某包：优先按该包落成「怎么写」，再按本局美学微调；不要重做文风问卷。
2. 否则继承美学体验与禁忌，改写成做法向句子。
3. 写纲领、遣词（含示范）、笔墨焦点、禁忌/不偏好。
   遣词用户未提段落形态时，默认写入：完整长自然段叙述，不要单句成段（篇幅数字交给「回复呈现」）。
4. 情境备用 = 写法档（体裁/调性容器），不是具体桥段。有切换则每条写：名字=档名（如「官能小说」「网文爽文」「展示恐怖」「展示情色」），用法=该档怎么遣词、笔墨落哪、何时切进来。无切换则 `[]`。用户若报出「当众折辱」「独处一室」这类场合，升一档写进对应写法档，场合本身不单列。
5. 自评 + 追问。故事怎么往前、用户输入用法交给「故事推进」，本步不写。

summary：`叙事指南 · …`
```

## principles

```principles
1. 感觉 vs 做法：美学写要什么爽；本步写怎么遣词、笔墨落哪。
2. 遣词与禁忌要可执行；绝对禁忌 ≠ 不偏好。
   用户未提及时：完整长自然段，不要单句成段。
3. 情境备用是写法档：名字用「官能小说」「网文爽文」「展示恐怖」「展示情色」同级；用法写该档遣词与何时切入。无切换则空数组。
4. 字数区间归「回复呈现」；推进与输入用法归「故事推进」。
```

## probe

```probe
本步只钉三件：遣词可执行、笔墨落点、绝对禁忌（含写法档有无切换）。

已在美学写清的感觉改写成做法向句子，不重问「想感受到什么」。
用户未提段落形态时：写入长自然段默认并简短确认即可。

缺遣词/笔墨/禁忌其中一件：在产物「追问」写 1～2 点（建议选项 + 短句示例）。三件够验收：`追问.题目` 为 `[]`。

用户谈到推进、停笔、大纲扩写：写入「开放问题」，交给「故事推进」。
用户谈到变量增减、生成规则、舞台百科：只抽取能改遣词 / 禁忌的一句，其余写入「开放问题」。
用户提到要换写法：收成写法档写入「情境备用」（官能 / 爽文 / 恐怖 / 情色这类），不追问具体场合怎么摆；没提则 `[]`。
字数问「回复呈现」；本步不追问字数。
```

硬规则：合法 JSON；示范至少 1 段；禁忌与不偏好都要有；禁止 order；summary 见 task。
情境备用若有：名字必须是写法档（官能小说 / 网文爽文 / 展示恐怖 / 展示情色 同级），用法写该档的遣词与切入口；不是「当众折辱」「物资告急」这类具体桥段。无切换则 `[]`。
不写「推进与决策」。

## checklist

```checklist
- [ ] 遣词+示范+禁忌够用？
- [ ] 情境备用若有，是否是写法档而非具体桥段？无切换是否为 `[]`？
- [ ] 未把推进/输入用法写进本步？
```
