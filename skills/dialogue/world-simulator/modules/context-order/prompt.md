# 上下文投影排序

> 技能文档。程序只切割下方 **fence 块**；`##` 标题仅供人读。  
> **先抄程序钉死的执行单元名册，再给每个已启用者分配上下文与顺序。**  
> 不发明执行单元，不重写设定长文，不演游玩选项。  
> 「对话.历史」也是可投影标签；见 `docs/context-fragment-design.md`。

## meta

```meta
name: 上下文投影排序
id: context-order
artifact: 设计.上下文投影排序
declaration: >
  收成前给已启用槽排扁平投影序（含对话.历史）；不发明槽、不重写长文、不演情节选择题
when: |
  游玩槽已确认（或可按默认），且主要上下文块已有可摘要产物，需要决定各执行单元看见什么、以何顺序插入。
  本步为〔程序步〕：上下文已多、即将收成时排入。
when_not: |
  体验/站位仍混沌 → 先「美学纲领与交互范式」。
  槽位未定且用户拒绝默认 → 先「游玩拓扑」。
  上游上下文仍大量空洞、无法判断稳/变 → 先补缺口，勿空排。
  只需勾选槽 → 「游玩拓扑」；上下文很少、只需合并终稿 → 「细化终稿」可按默认序退化。
boundary: |
  本技能：抄名册 → 凭各块 brief/挂载/稳变 给每槽 inserts[]。
  名册权威在程序（及已勾选的游玩拓扑）；本步不增白名单外 id。
  中段技能可带 mount 与稳/变；最终 order 以本步为准。
  细化终稿：把本步排序表收进运行规格 context_order；本步不输出完整 设计.worker集。
  禁止把依赖产物里的游玩示例（迎上去/推开/反客为主 等）当成当前要问的题。
feeds: design_only
```

## opening

```opening
按已验收产物的概括，给每个固定执行单元分配上下文顺序（只排序，不改设定、不演游玩）。

名册由程序钉死：主世界层 / 叙事转述 / 旁观维护（回合末）/ 可选角色视角。
无机遇裁定槽；「设计.随机范围整理」按 mount 挂进主世界层（等）inserts 即可。
若前面产物够用，直接回复「按已有概括排序」。
```

## task

```task
你正在执行「上下文投影排序」。产物写入「设计.上下文投影排序」。

执行顺序（必须按此，禁止颠倒）：
1. **抄名册**：以程序注入的【本局固定执行单元】为准列出 agents[]（id / label / enabled / when / duty）。
   启用与否跟已勾选游玩拓扑走；未勾选则按默认：主世界层+转述+旁观开，角色视角关（无机遇槽）。
2. **再分配**：只对 enabled 的每轮槽写 inserts（order / ref / projection / 可选 note）。
   凭上游 **brief、挂载、稳变** 排序，禁止把百科全文再读一遍当创作。

规则：
1. 禁止发明白名单外 id（含画图、机遇裁定等未入册槽）。
2. 禁止重写上游长文；只写顺序与投影。
3. 每轮槽：order 0＝该槽固定人设；其后按「稳→对话.历史→易变」软排。
4. 主世界层必须含 ref=`对话.历史`（默认 projection=summary）；转述与旁观维护默认不含历史。
5. 主世界层应挂「设计.叙事指南」「设计.故事推进」（工序编排则为「设计.叙事指南与故事推进」）等 mount 到 gm 的块；有「设计.随机范围整理」则挂 gm（summary 即可）；转述只读本轮正文（输出.用户展示）+ 文风/壳。
6. 旁观维护在回合末：须含「输出.用户展示」与变量合同，不含历史。
7. 越稳越靠前；本轮输入/真值/正文通常在历史之后。
8. 同一内容可挂多槽。
9. summary：如 `投影排序 · 旁观+主世界层+转述`。

若程序已发默认问题：禁止重复同一开场；用户说「按已有概括排序」或等价同意 → **立刻产出表**，禁止再问情节内选项。
禁止 askUser 出游玩选择题（迎上去/推开她/反客为主 等）。材料已齐则顶层 askUser 为 null。
```

## principles

```principles
1. 名册先行：先有哪些执行单元，再谈每单元看什么。
2. 晚排序：此时才能区分常变与重要；勿回退去发明新槽。
3. 概括驱动：凭摘要与稳变信号排序，不把设定长文再当创作。
4. 历史是标签：用投影裁剪；旁观维护默认不进对话.历史。
5. 缓存优先：少变块靠前；高频变块靠后。
6. 投影分级：full / summary / fields / fixed——历史默认 summary。
7. 可修订已有排序表；用户改稳变判断时只改序，不改上游产物 id。
```

## probe

```probe
一次 askUser 1～2 点，且必须关于「挂哪槽 / 稳还是变 / 投影级别」：
- 某块稳/变判断冲突时，问更偏「少改利缓存」还是「每轮必须看见」。
- 角色视角若开启，问哪些块禁止进主世界层。
已齐则直接产出，勿为凑问题而问。禁止问剧情里发生什么、谁敲门、玩家选哪一招。
```

## checklist

```checklist
- [ ] agents 只使用程序名册 id（auditor / gm / narrator / perspective）；无 chance
- [ ] 未发明白名单外执行单元
- [ ] 未重写上游长文，只有排序/投影
- [ ] 未把游玩选项示例当成当前提问
- [ ] 已启用的每轮槽有 order 0 人设位
- [ ] 主世界层含「对话.历史」；转述与旁观若启用则默认无历史
- [ ] 与游玩拓扑勾选一致（默认仅 gm）；有随机范围表则已挂 gm
- [ ] 少变块整体靠前、本轮/真值靠后（软规则）
```
