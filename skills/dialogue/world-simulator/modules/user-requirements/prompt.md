# 用户需求

> 对话落盘与工序编排共用。程序只切割下方 **fence 块**；`##` 标题仅供人读。  
> 产物外壳：`docs/context-fragment-design.md`。  
> 从全局【偏好库】选用硬约束写入本局；不管文风遣词（那是叙事指南）。

## meta

```meta
name: 用户需求
id: user-requirements
artifact: 设计.用户需求
declaration: >
  把跨局偏好库里对本局生效的硬约束（禁区/纠偏/默认取向）落成可执行条目；
  不重做文风问卷，也不钉体验站位
when: |
  提示中有【偏好库 · 可选用】且库非空，或用户主动谈跨局禁区、绝对不要写什么、默认取向要进本局。
  开局常见：库里已有起步条目且本局尚无「设计.用户需求」。
when_not: |
  本局已有等价「设计.用户需求」且用户未要求改偏好 → 不重复排。
  只谈文风遣词/示范 → 「叙事指南」（工序编排：「叙事指南与故事推进」）。
  只谈体验站位/核心感觉 → 「美学纲领与交互范式」。
  库空且用户未提硬约束 → 不排。
boundary: |
  本技能：一份 context-fragment，写清本局必须遵守的硬约束列表。
  文风：叙事指南。体验：美学。推进：故事推进。
feeds: narrator,gm
```

## opening

```opening
偏好库里已有跨局硬约束时，请确认本局要带哪些（想到什么写什么）：

1. 哪些条目本局生效？有没有要改写、收紧或放宽的？
2. 有没有库外、但本局一定要遵守的禁区/纠偏？（一句话即可）
```

## task

```task
你正在执行「用户需求」。产物必须是 **context-fragment.v1** JSON，写入「设计.用户需求」。

作用对象是本局游玩固定上下文（主世界层与转述都读）。只写硬约束，不写遣词示范。

执行顺序：
1. 若提示中有【偏好库 · 可选用】：默认把 active 条目纳入，再按用户点名增删/改写；勿整库无脑粘贴原文若用户只要子集。
2. 用户本局补充的禁区/纠偏：写成可执行短句，与库条并列。
3. 自评 + 追问。文风交给叙事指南；体验站位交给美学。

summary：`用户需求 · …`
```

## principles

```principles
1. 硬约束 ≠ 文风：禁区/取向/纠偏归本步；遣词与示范归叙事指南。
2. 条目要短、可执行；写「不要 X，改做 Y」优于空泛「注意分寸」。
3. 库空且用户无补充 → 可不排本步；有库则优先落盘，勿装作没有。
4. 与本局世界观许可冲突时，以本步产物为准（游玩侧已约定）。
```

## probe

```probe
本步只钉：本局生效的硬约束列表是否够用、有无漏掉用户点名的禁区。

库条目用户未否决的默认纳入；用户只要子集则只写子集。
缺关键禁区且用户话里有信号：在「追问」写 1 点。够用：`追问.题目` 为 `[]`。

用户谈到文风遣词：写入「开放问题」，交给叙事指南。
用户谈到站位/核心感觉：写入「开放问题」，交给美学。
```

## output

```output
{
  "schema": "context-fragment.v1",
  "技能": "用户需求",
  "brief": "一句话：本局硬约束重心",
  "mount": ["world-simulator", "narrator"],
  "稳变": "stable",
  "正文": {
    "来源说明": "偏好库选用 + 本局补充",
    "约束": [
      "短、可执行的一条",
      "…"
    ]
  },
  "自评": {
    "维度": [
      { "名": "可执行", "分数": 8, "说明": "…" },
      { "名": "覆盖用户点名", "分数": 8, "说明": "…" }
    ],
    "薄弱点": ""
  },
  "追问": { "导语": "", "题目": [] },
  "开放问题": []
}
```

硬规则：合法 JSON；`约束` 至少 1 条（若用户明确「本局不要任何跨局偏好」则可写一条「本局不套用偏好库」）；禁止 order。

## checklist

```checklist
- [ ] 约束短且可执行？
- [ ] 未把文风遣词/体验站位写进本步？
- [ ] 用户点名的禁区已覆盖或已追问？
```

## examples

```examples
好：纳入偏好库 NTR/取向两条，并加一条「不要反复报精确数字」。
坏：写成叙事遣词示范；或整库粘贴却无视用户「只要取向那条」。
```
