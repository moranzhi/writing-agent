# 世界法则

## meta

```meta
name: 世界法则
id: mechanism
artifact: 设计.世界法则
declaration: >
  写出这个世界相对熟悉基底的根本变造及其连锁后果，以及金手指、玩法系统的固定规则；
  供主世界层判断「在这个世界里，这件事意味着什么、会引来什么」。
when: |
  用户给出了与现实或原作不同的世界前提（超常力量、社会常态、禁忌、缺失之物），且它会持续改变人们怎样看待、处理玩家要做的事时使用。
  本局有金手指或玩法系统，需要固定的触发条件与总则时使用。档位全表、价目、社会阶梯归拓扑图谱。
when_not: |
  世界与熟悉基底无差别，也没有需要固定规则的能力或系统 → 不使用。
  只是身份或开场处境 → 主角设定 / 开场白。
  地点、势力分布与主要场所 → 舞台骨架。
  社会阶梯、境界、价目、兑换等级的全表 → 拓扑图谱；本步只点图名。
  某人或某类人对玩家的态度、好感、屈服阶段 → 具体实例 / 生成规则 / 变量设计。
  怎么写、写多细 → 叙事指南。
boundary: |
  本步只写对整个世界客观成立的规则：变造本身，它在制度、权力、日常里的连锁，触碰它的代价与边界；能力与系统的触发和总则。档表不写在这里。
  规则不预定任何人对玩家的反应或结局；人物如何反应由其性格、利益与当前变量推出。
  舞台骨架的「必要变造」只留一句台上结果，完整连锁写在本步。
feeds: gm
```

## opening

```opening
说说这个世界和熟悉的现实（或原作）哪里不一样，这些不同让社会、权力和日常变成了什么样。如果有金手指或玩法系统，说说它的触发条件和总则；整张档表交给拓扑图谱。
```

## task

```task
把材料整理为 `设计.世界法则`：这个世界对玩家要做的事持什么态度，由哪些规则决定。

先从美学纲领找出玩家反复要做的那件事（讲黄段子、越级修炼、复制能力、扳倒高位者……），再问：在这个世界里，这件事是什么地位——稀缺、禁忌、违法、被垄断、有代价，还是寻常？给出这个地位的世界前提，就是要写的法则。每条写：
1. `法则`：世界里成立什么，何时对谁生效。一到两句，主语是世界或某类人，不是玩家。
2. `连锁`：因此世界长成什么样。往下推到制度、权力分布、风俗日常、普通人的常见看法，每条一句，1～4 条。
3. `代价与边界`：有人去做相关的事会撞上什么（处罚、排斥、追捕、反噬、争夺），法则在哪里失效。无则省略。
4. 法则依赖社会阶梯、境界、价目或兑换等级时，在法则或连锁里点拓扑图名，不抄档表。

写完核对两件事：删掉所有提到玩家的句子，每条法则仍成立；没有一句替某类人预定了对玩家的态度或结局。

材料够就成稿；会改变法则或连锁方向的缺口进 `self_score.gap`。产物正文只含机制 JSON，不含评分、诊断或追问。
```

## principles

```principles
1. 世界给体验以分量，不替体验兑现结果。用户要的感觉（爽、禁忌、反差）归美学纲领；本步写让这种感觉成立的地形：这件事为什么难、为什么稀罕、为什么冒险。写成「某类人都喜欢 / 都会屈服 / 绝不反抗」，就是把愿望写成了法则；改回世界前提，人物反应交给实例与变量。
2. 两类来源，按序写：世界变造（与基底不同的物理、超常力量、社会常态、禁忌或缺失）优先且写全；其次是特殊力量规则（金手指、功法、血统：触发、效果、限制）。社会阶梯、境界、价目、兑换等级的全表归拓扑图谱。
3. 用户描述世界时给出的每一处变造，都要落到某条法则或连锁里，与主角无关的也一样。只写主角身上的力量、漏掉世界本身的不同，是本步最常见的偏法。
4. 连锁按常识与人性往下推：谁受益、谁吃亏、制度怎样适应、普通人信什么。可以补出用户没说的合理后果，不得与用户已说的冲突；推不准且会改方向的进 gap。
5. 用户否定过的方向本身就是法则（如「古武加入不意味着能单凭武力颠覆一切」），写进去，其它条服从它。
6. 同一事实只出现一次。场所写进舞台骨架，体验句留在美学纲领，遣词与「重点描写什么」归叙事指南。
7. 一条说清就停，不为凑数拆条。
```

## output

```output
{
  "schema": "context-fragment.v1",
  "技能": "世界法则",
  "brief": "一句话：这个世界哪些根本不同，让玩家要做的事有了什么分量",
  "mount": ["world-simulator"],
  "稳变": "stable",
  "正文": {
    "既成机制": [
      {
        "名称": "简短稳定的人话名",
        "法则": "世界里成立什么；何时对谁生效",
        "连锁": ["因此世界在制度、权力、日常或普遍看法上变成什么样"],
        "代价与边界": ["可选；触碰时撞上什么，法则在哪里失效"]
      }
    ],
    "共同作用": []
  }
}
```

硬规则：
1. 合法 JSON；`既成机制` 可多条；`mount` 固定 `["world-simulator"]`。
2. 每条必填 `名称`、`法则`、`连锁`；`代价与边界` 无则整项省略。不写档表、价目全表。
3. 正文不出现某人或某类人对玩家的态度、好感、屈服阶段或必然结局；不出现「详写」「重点刻画」一类写法指令。
4. `共同作用` 每项一句，只写两条法则相互放大或制约后的世界后果；无则 `[]`。
5. 正文不含评分、诊断、追问或历史百科。

## score

```score
世界客观度：
- 5：每条对整个世界成立，删去玩家仍成立；无人物态度或结局预设。
- 3：主体客观，夹一句「某类人会配合 / 屈服」或一条写法指令。
- 1：法则主要在描述人物如何回应玩家，或在教如何攻略。

连锁充分度：
- 5：用户给出的变造全部落下，且推到制度、权力或日常；主世界层能据此回答「在这个世界里做某事会怎样」。
- 3：变造齐了但连锁只有一层，或漏了一处与主角无关的变造。
- 1：只有题材标签，或只写了主角的力量。

承重克制度：
- 5：每条拿掉都会改变世界反馈；无场所、名片、文风内容；同一事实只出现一次。
- 3：夹一条该交给其它能力的内容，或两条互相复读。
- 1：凑数、百科化，或把场所、人物、体验句挤进来。
```


## examples

```examples
没有黄段子的世界：
- 好：法则「这个世界的语言与文化里没有性玩笑；性只在医疗与法律语境里被提起」。连锁「公开谈论性视同猥亵，可被举报处罚」「人们没有接这种话的经验，第一反应多是困惑或惊骇」「极少数地下圈子私下流传，被抓即身败名裂」。代价与边界「说出口的人承担社会性死亡与治安风险；医生、律师在职业语境内例外」。
- 偏：「玩家很爱讲黄段子」「某某很爱听」。前者是体验，归美学纲领；谁会好奇、谁会举报，由各人性格推出。

世界变造写全：
- 「阴气偏重，女性习武天然占优」→ 连锁「古武世家上层多为女性」「表世界招聘与言论默认偏向女性，女权乃至种姓式言论常见」「男性高手稀少，罕见的男性天才格外扎眼」。只写主角禁功的突破与反噬、漏掉这条，就是偏了。
- 「古武者能绕开任何安保近身刺杀，但扛不住重武器」→ 连锁「真正掌权的是古武世家或受其庇护者」「古武者不公开对抗国家机器，靠隐秘施压」「市井当古武是传言」。
- 「超级英雄是合法职业，接替了旧时代偶像的商业位置」→ 连锁「经纪公司与广告左右英雄的曝光与资源」「守序多因利益，被逼急可以转做反派，名声不是绝对枷锁」。
- 「灵气重回环境」→ 连锁「生物可经接触与修炼强化或异变」「浓度与方法决定速度和可控度」「资源价值与既有力量关系被改写」。

特殊力量与系统：
- 复制金手指：法则写触发与总则（对方无感、不被削弱；装备、金钱、智力、寄生体不可复制）。五档效果写成拓扑图谱的一条链；主角设定只点图名。
- 跨世界对数等级与价目 → 全表是一张 `path` 拓扑；本步只写「强度与价格按那张图」。生成规则和变量只填阶名。

偏了就改回：
- 「恶女必经五阶段：自负→惊恐→……→顺从」→ 删。各人怎么破防写在实例性格，进度交给变量。
- 「养母绝不会对主角动手，只会包容」→ 删。这是人物关系，写在实例与变量。
- 「主角出手必然形成绝对压制」→ 删；用户说过武力不能颠覆一切时，改写成法则「权与钱仍是表世界主轴，武力不能直接换来合法地位与资产」。
- 「推演时详写其神态与身体反差」→ 删，写法归叙事指南。
```
