# 实现机制

## meta

```meta
name: 实现机制
id: mechanism
artifact: 设计.实现机制
declaration: >
  保存世界中稳定成立的因果法则，供主世界层推演事件后果、剧情变化和人物反应；一次可写多条共同作用的机制。
when: |
  本局存在拿掉后会改变故事骨架的既成法则，且后续需要据此推演环境变化、事件后果或人物反应时使用。
when_not: |
  只有熟悉常识，没有特殊因果法则 → 不使用。
  地点、势力与社会格局 → 舞台骨架；多份人物或要先审字段的名片 → 生成规则，单条字段很少的具名内容才归具体实例；字段合同 → 生成规则。
boundary: |
  本能力交稳定因果，不预写唯一剧情，也不把所有人物钉成同一种反应。
  不解释起源，不扩写世界百科，不制定推进节奏、变量表或检定公式。
feeds: gm
```

## opening

```opening
说说这个世界有哪些已经成立、会持续改变事件后果的法则。重点是它如何起作用，以及不同处境和人物会因此面对什么；多条机制可以一起写清。
```

## task

```task
把本局承重的既成因果法则整理为实现机制，写入 `设计.实现机制`。一个产物可以包含多条共同作用的机制；分别写清法则内容、生效方式、因果影响和推演口径，再说明机制之间如何共同作用。

先在内部对每条候选做移除检验：拿掉后故事骨架是否改变。`缺失后果`只用于筛选，不得写进实际产物。机制应让主世界层能够推演事件怎样发展、不同人物可能怎样反应，但不得指定唯一剧情或统一人物反应。

材料足够便直接成稿；真正会改变法则内容的缺口交给 `self_score.gap`。产物正文不放评分、诊断、追问或开放问题。
```

## principles

```principles
1. 机制是稳定因果：写世界承认什么、何时生效、会带来什么后果。
2. 内部使用移除检验筛选承重法则；只能回答“更丰富”或“以后也许有用”的候选不纳入。缺失后果不输出。
3. 因果影响写行动可能性、代价、资源与关系怎样改变；推演口径写推演情节和人物反应时必须考虑什么。
4. 人物反应保持开放：同一机制下，人物可因认知、利益、身份和性格不同而隐藏、合作、利用、抵抗或误判。
5. 多条机制可一次生成。分别写清后，再说明它们是前提、叠加、制衡还是反馈循环；没有关系则不硬连。
6. 机制不等于题材标签。“灵气复苏”“全民直播求生”必须拆成可推演的生效方式与因果链。
7. 一句话够用便停止；不补起源史、体系百科、人物卡、剧情大纲或推进节奏。
```

硬规则：
1. 输出合法 JSON；`既成机制` 可含多条承重机制。
2. `缺失后果`、移除检验和被淘汰候选只用于内部推理，不得进入正文。
3. 每条机制必须写 `法则内容 / 生效方式 / 因果影响 / 推演口径`。
4. `共同作用` 只写真实存在的机制关系；无则 `[]`。
5. 推演口径提供因果依据，不指定唯一剧情，也不规定所有人物作同一种反应。
6. 不在产物正文写自评、追问、开放问题、起源百科或检定公式。
7. `mount` 固定为 `["world-simulator"]`。

## score

```score
骨架必要度：
- 5：每条都是拿掉后会改变故事骨架的承重法则，没有常识、装饰或下游细节。
- 3：主体承重，但夹有一条作用较弱或可交给其它能力的内容。
- 1：只有题材标签或装饰设定，没有稳定承重法则。

因果清晰度：
- 5：生效条件与影响链清楚，能据此推演环境、事件和关系怎样变化。
- 3：法则方向正确，但生效方式或一段关键因果仍需猜测。
- 1：只说“存在某设定”，无法推出后果。

推演开放度：
- 5：能支持人物按不同认知、利益、身份和性格作出多种合理反应，而不失去法则约束。
- 3：提供了反应依据，但部分表述暗含单一路线。
- 1：直接预写唯一剧情，或把所有人物规定成同一种反应。
```

## checklist

```checklist
- [ ] 每条候选已在内部通过移除检验，且缺失后果未写入产物？
- [ ] 法则内容、生效方式、因果影响与推演口径均可执行？
- [ ] 多条机制的共同作用已写清，或明确无须关联？
- [ ] 能支持不同人物作出不同但合理的反应？
- [ ] 未写成题材标签、世界百科、剧情大纲或裁定表？
- [ ] 产物正文不含评分、诊断、追问？
```

## examples

```examples
灵气复苏：
- 灵气重新进入环境，生物可吸收并强化、异变；浓度、接触方式与修炼方法影响变化速度和可控程度。
- 因果上会改变资源价值和既有力量关系；推演人物时结合其认知、资源、身份得失与控制能力，不能默认人人都追求修炼。

全民直播求生：
- 可拆为“强制进入求生场”“关键行为公开直播”“观众反馈可进入场内（若本局采用）”等多条机制。
- 公开评价与即时生存会共同改变选择代价；人物是否表演、隐藏或利用镜头，应由其是否在乎声誉、是否相信能返回现实等条件推出。
- 观众若只能观看，就不能推演出打赏资源；边界会直接改变因果链。
```
