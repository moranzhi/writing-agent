# 舞台骨架

## meta

```meta
name: 舞台骨架
id: world-blueprint
artifact: 设计.舞台骨架
declaration: >
  保存会反复影响世界反馈的外部舞台：熟悉基底、必要变造、核心运转和主要活动场所。
  推进时据此知道该推哪些地方，以及玩家行为在哪个尺度上产生回馈。
when: |
  核心体验依赖外部环境、社会力量或世界状况持续作出一致反馈，而现有材料还不足以支撑这些反馈时使用。
  是否换区不是判断标准：跨越多地可以需要舞台骨架；一室之内的朝堂、审讯或家庭关系同样可以需要。
when_not: |
  熟悉现实基底已经够用，地点和外部格局不会改变核心体验或世界反馈时不使用。
  既成硬法则归世界法则；本步最多引用其台上结果。
  多份人物或要先审字段的名片归生成规则；单条字段很少的具名内容归具体实例。
  重点在节点与连接本身时归拓扑图谱。
boundary: |
  本步交四块会上台并反复有用的外部事实：熟悉基底、必要变造、核心运转、主要活动场所。
  在这四块上再写清推进落点与回馈尺度：该推哪些地方，玩家行为在哪一层产生回馈。
  熟悉常识默认继承；体验碰不到的范围写进留白。硬法则正文、人物名片、完整地图、历史与百科交给对应能力。
feeds: gm
```

## opening

```opening
说说这局里会反复影响你的外部舞台：以什么熟悉世界为基底，哪里不同，哪些运转和场所会持续参与反馈。再补一句：推进时该推哪些地方，你的行为会在哪一层尺度上回馈。
```

## task

```task
把材料整理为 `设计.舞台骨架`。先写最短的 `熟悉基底` 和回馈 `尺度`，再列会改变台上反馈的 `必要变造`，然后写 `核心运转` 和会反复上台的 `主要舞台`；碰不到的范围进 `留白边界`。

四块写完后，核对推进能不能用：`主要舞台` 是该推的地方；`尺度`（或某一舞台自有的一层）是玩家行为产生回馈的层级。`核心运转` 写力量或状况怎样持续影响玩家；`玩家如何接触` 写这一处怎么进场、碰到什么、回馈落在哪。两处说同一句时，删舞台侧的因果复读，场所与回馈层留下。

材料够就成稿。两种尺度或运转会导致明显不同反馈、又无法从材料判定时，缺口进 `self_score.gap`。产物正文只含舞台 JSON，不含评分、诊断或追问。
```

## principles

```principles
1. 舞台以世界怎样回应玩家为准，不以换区数量、地图大小或题材类型为准。
2. `尺度` 由体验会碰到的边界正推，也是行为回馈的层级。同是「现代都市」：财阀压迫收到国家与资本网；大学生活收到一座城或一所学校。某一舞台的回馈层与全局不同时，写在该舞台上。
3. 熟悉常识默认继承。`必要变造` 只列相对基底、且会改变世界反馈的差异（一句一条）。差异本质是因果法则时，法则进世界法则；本步写台上看得见的结果。
4. `核心运转` 是社会力量、阶层关系、周期事件、资源、禁忌、日常秩序，以及用户点名的灾变、祭祀、异界出口。写它怎样持续影响玩家和主要舞台。
5. `主要舞台` 是会反复上台的空间、机构、社会层或一间房，也是推进时要推的地方。写玩家在这里做什么、会碰到谁或什么、回馈落在哪一层，写到能稳定反馈为止。玩法标签不代替场所。
6. 硬法则只引用台上结果；多张名片共享的台上格局写在本步，生成规则只引用。用户未触及的地区、历史、势力不补全，进留白。类型名只作氛围参照，不自动塞该类型常见地理与谱系。
```

硬规则：
1. 合法 JSON；无内容的可选字段整项省略；`mount` 固定 `["world-simulator"]`。
2. 四块都写：熟悉基底、必要变造（无则省略该项）、核心运转、主要舞台。`主要舞台` 是推进落点，不因与运转相关就删掉。
3. `玩家如何接触` 不复述对应运转的 `如何作用`；复读删因果句，场所与回馈层留下。`关键运转` 只写名称。
4. `必要变造` 不写法则全文、价目或检定。正文不含评分、诊断、追问、百科或人物名片。

## score

```score
支撑度：
- 5：熟悉基底、变造、运转和主要场所足以稳定反馈；并能指出该推哪些地方、行为在哪一层回馈。
- 3：四块方向对，但缺一项会反复影响体验的条件，或回馈层不清。
- 1：只有题材或地点标签，世界如何回应、推进该推哪都无从判断。

克制度：
- 5：只写会上台且反复有用的内容；常识继承；其余留白；运转与舞台无同义复读。
- 3：夹带少量暂不影响游玩的设定，或有一处舞台在复读运转。
- 1：写成世界百科，或把变造、舞台写成硬法则与玩法标签。
```

## examples

```examples
好：
- 普通大学生活：熟悉基底是现代都市，尺度是一所学校（冲突回馈落在系馆与宿舍，不落到国家）。必要变造若无则省略。主要舞台写系馆、宿舍、社团：玩家在那里做什么、碰到谁、回馈落在校园这一层。国家政治进留白。
- 财阀压迫：同一都市基底，尺度升到国家与资本网。核心运转写资本与名声怎样持续施压；主要舞台写财团、宴会、听证，并写明一次出手的回馈落在资本与名声层。
- 一室朝堂：主要舞台只有一座殿。核心运转写皇权与派系怎样在奏对里记账；接触栏写入殿后对面是谁、当场回馈是被谁记账。
- 必要变造短写：「市井当古武是传言，权贵圈才兑现」；刺杀阈值等因果进世界法则。

缺料时：
- 两种尺度都会改反馈且材料未钉 → `self_score.gap`。
- 只有咖啡馆店主姓名、无台上作用 → 留给具体实例，不写进本步。

偏了就改回：
- 用「该推哪里、回馈哪一层」替换掉基底、变造、运转、场所 → 四块补回，落点与尺度写在尺度和主要舞台上。
- 接触栏只是把「如何作用」换壳 → 删复读，留下进场、在场对象和这一处的回馈层。
- 必要变造写成核威慑长因果 → 因果进机制，变造改成台上可见的圈层差异。
- 接触栏写成「正义堕落、战败调教」→ 改成该场所谁进出、玩家以何身份入场、回馈落在哪一层。
```
