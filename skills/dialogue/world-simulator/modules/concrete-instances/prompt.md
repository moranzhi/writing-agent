# 具体实例

## meta

```meta
name: 具体实例
id: concrete-instances
artifact: 设计.具体实例
declaration: >
  按已有生成规则填写一条记录，单独落成一份产物。没有规则时，只留下用户点名的一条字段很少的具名内容。
when: |
  已有生成规则，要按该规则写入一条种子或开局记录时使用。每条记录单独一份产物。
  还没有规则时，只在用户明确要求留下一条字段很少的具名内容时使用。
when_not: |
  还没有规则，而对象有两份以上，或字段较多、需要先审字段和填写工作流 → 先写生成规则。
  内容不重要、游玩时现写就够 → 不落本产物。
  一张有节点和连接的结构图 → 拓扑图谱。
  规则写明创作期不预填、只在游玩期生成 → 本步不写记录。
boundary: |
  本步只交一条按合同填好的记录。有规则则按字段、池或提示、地板和工作流填写，填到地板即停。
  不重议合同，不把规则里的提示、分级表象或反例抄成正文，不预写尚未发生的场面。
  世界格局与硬法则留在舞台骨架和世界法则，本步只写这一条自己的事实。
feeds: gm
```

## opening

```opening
先说这条记录是谁、依哪条生成规则。没有规则、又只是用户点名的一条简单内容，直接写这一条。
```

## task

```task
写出一条具体实例，写入 `设计.具体实例#中文名`。一份产物只含一条记录。用户一次给出多条时，每条各写一份；交来的是记录数组时，程序按条拆开。

有生成规则时：认定规则的中文名，按字段、池或提示、地板和填写工作流填这一条。用户已写明的专名与结果保持原样。未写字段从已有材料补到该字段的地板：地板是最低要看见或碰到的事实，补完即停。无规则且只是一条字段很少的具名内容时：只写用户给出的字段。

规则为同批时：一次写齐本批，`记录` 写成数组，每项一条并带上姓名或名称，程序按条拆成多份。先定各条如何互指、对立、同场，再填字段。

材料够就成稿。缺的是合同本身时，回到生成规则，不在这里补合同。规则里的硬门槛（年龄、禁止项、档位）对不上材料时，不把这条写成违规内容，缺口进 `self_score.gap`。正文只含记录 JSON，不含评分、诊断或追问。
```

## principles

```principles
1. 有规则：字段名、取值方式、工作流与依赖以规则为准。不增删字段，不改池。
2. 池选取按合理度选。提示是范围，按范围写这一条的事实，不把提示里的方向句原样贴进记录。
3. 按工作流：先定会约束后面的项，再填其余。填完要能过规则的自检。
4. 一份产物一条记录。同批一次写齐：先对齐关系，再填字段。互指的专名与事由必须一致，同一次写完。
5. 句子级字段写到地板规定的可感知事实即停。词条、档位、数字保持短值。只丢一个词、低于地板，不算填完；写成一场戏、一段台词或「以后会怎样沦陷」，算写过了，收回到事实。
6. 命门、突破口、限制类字段写失效条件：什么事实一发生，这项依仗就变了。不写征服过程。外貌写能认出的年龄感、衣服和一处外形，不写尚未发生的身体反应。
7. 分级字段只填档位短值。表象留在规则的分级表现里，不抄进记录。舞台、机制、美学里已有的句子不在记录里再写一遍。
8. 无规则只写用户点名的那一条，字段保持很少。
9. 给人读的键和专名用中文。英文专名音译，不把英文原名留在字段值里。外壳的 schema、brief、mount 保持既有键。
```

```output
  "schema": "context-fragment.v1",
  "技能": "具体实例",
  "brief": "这一条是谁、依哪条规则",
  "mount": ["world-simulator"],
  "稳变": "stable",
  "正文": {
    "规则": "所依生成规则的中文名；无规则时省略",
    "名称": "这条记录的中文名",
    "记录": {
      "字段名": "按规则填到地板的事实；档位与数字保持短值"
    }
  }
}
```

硬规则：
1. 合法 JSON。`记录` 是单个对象；同批时写成至少 2 项的对象数组，每项带姓名或名称。`名称` 用中文，并与这条记录的主名称一致。`mount` 固定 `["world-simulator"]`。
2. 有规则时 `记录` 的键必须来自该规则字段，不得增删。
3. 每个句子级字段停在地板：可核对的事实，不附场面、台词或预告。分级只填短值。
4. 无规则时省略 `规则`，`记录` 只含用户给出的少量简单字段。
5. 字段名和专名用中文；英文专名音译。正文不含自评、追问、合同草稿或规则条文。

## score

```score
工作流符合度：
- 5：按规则字段与工作流填写；句子级达到地板并停在事实；同批互指一致；用户已定内容未改。
- 3：大体按工作流，但有一处低于地板，或有一句在预写场面。
- 1：乱增字段、忽略地板写成整场戏、同批对不上，或改掉用户已定内容。
```

## checklist

```checklist
- [ ] 有规则则键与工作流一致；无规则则只是一条字段很少的内容？
- [ ] 一份产物一条记录，名称是中文？
- [ ] 同批已一次写齐，互指的专名与事由一致？
- [ ] 句子级字段达到地板且停在事实，没有场面或预告？
- [ ] 分级只填短值；硬门槛对不上时已进 gap 而不是写违规记录？
- [ ] 用户已定专名未改，英文专名已音译？
- [ ] 正文无评分、诊断、追问？
```

## examples

```examples
好：
- 同批仇敌二人：一次写齐。甲的关系写乙与夺位之事，乙写甲与同一件事。
- 外貌地板是年龄感、一套衣服、一处外形：写「三十四岁，黑套裙，金丝眼镜，坐在桌沿按着档案」。不写被制服后的神态。
- 命门：写「三份签章权被公开或被上层改掉，高位当天失效；失效前她加价，失效后改口说补件是自愿」。不写一场惩戒。
- 阶层填「T2·豪门顶流」。不把分级表现里的表象再抄进记录。

缺料时：
- 没有可依的规则，又不止一条简单具名内容 → 先写生成规则。
- 材料过不了规则的年龄或禁止项 → 不填成违规记录，进 `self_score.gap`。

偏了就改回：
- 命门写成完整征服过程 → 收成「什么事实让这项依仗失效」。
- 外貌后半段写成身体反应 → 删到能认出的外形为止。
- 把规则提示里的方向句原样贴进字段 → 改成这一条自己的事实，仍落在该范围内。
- 记录里重写「古武核威慑」→ 删掉，留在世界法则；「五阶段崩解」这类全员反应链不写，这一条怎么破防由她的性格与命门推出。
```
