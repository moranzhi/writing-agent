## opening

```opening
先用几句话抓住你要的世界和体验核心（想到什么写什么，不必整齐）：

1. 原型世界是什么？变在哪里？
   例：丧尸世界，但只有我不会被感染；现代都市，但灵异是真的；也可以只说「现代都市」，变点稍后补。

2. 你代入吗？希望自己站在什么位置？
   · 完全代入（我就是那个人，TA 的遭遇≈我的遭遇）
   · 部分代入 / 跟着体验（有距离）
   · 操控或旁观（角色是棋子/观察对象）
   · 其它（请写明）

3. 你最想在这局里反复获得什么体验？
   一句话即可——权力、求生紧张、关系拉扯、解谜、荣耀、禁忌刺激……用你自己的词。
```

## task

```task
从用户材料提取体验契约，写入 `设计.美学纲领`。它给后续能力做取舍，不进游玩投影。产物回答两件事，并留下三句短锚：

1. 美学纲领：用户最想反复获得什么体验，它靠什么关系或处境反复发生，呈现时的尺度。体验本身只写在 `体验内核`。
2. 背景与规则：删掉就会让这份体验不成立的最小前提，写成后续能原句引用的短句。
3. `体验锚定`：站位、核心感觉、轮转停点各一句。完整的谁代写、谁裁定、怎么停笔，留给故事推进与交互范式。

保留用户自己的重点、用词和尺度。材料不足时少写或写「未定」，真正影响体验的缺口进 `self_score.gap`。正文不含评分、诊断或追问。
```

## principles

```principles
1. 核心是用户想反复获得的体验。其余字段只为让它稳定发生。设定变长时，先核对体验句还在不在。
2. 体验不是题材、剧情简介或情绪标签。写用户怎么参与、它怎样反复发生。同一设定可以要荣耀、自由或血与酒，只写这个人要的那一个。
3. 先抓「原型 + 变在哪里」。`核心内核` 只留删掉体验就不成立的那一句关系、社会前提或规则。场所、因果链、价目不在这里展开。
4. 用户说不清时，用两种站位或两种感觉的短场景让用户选；问在回复里，不写进产物。用户改口导致内核变了，整份重写，不在旧契约后打补丁。
5. 尺度按用户给的写进 `边界与尺度`：服务体验的用法，以及真正的禁忌。不替用户加码或减码。
6. `发生方式`、`角色人文`、`作用方式`、`描写焦点` 与体验内核或核心内核同义时整项省略。描写焦点只点注意力放在哪类瞬间，不写遣词，不写示范段，不写权限表。
```

## probe

```probe
本步最先要钉清三件：站位（代入还是旁观、镜头看哪、爽从哪来）、核心感觉（反复感受到什么）、轮转停点（何时等用户）。三件写进 `体验锚定`；开场白写入前程序会检查它们。

用户首句、默认问题首答或黑板「用户.需求」里已有的直接采纳，已答清的不重问。

缺其中一件：回复里只问这一件，给 2～3 个带短场景的建议选项，不问开放式「你还想要什么」。三件已清：再挑尺度或描写焦点里最影响体验的一点给选项；权限和停笔做法留给故事推进与交互范式，本步不再追问。

用户讲到人物、舞台、规则细节：只抽取能改变体验、站位或权限的那一句写进正文，其余留给对应能力，本步不追问细节。
```

## score

```score
美学纲领：
- 5：体验内核写清反复感到什么、怎样兑现；可选槽没有把这句话再写一遍；尺度贴用户原话。
- 3：方向对，但仍是题材或情绪标签，或发生方式在复读内核。

- 5：站位、核心感觉、轮转停点各是一句可核对的短锚，没有展开成权限表。
- 3：三件都有，但某一件是空话或和体验内核无关。
- 1：缺件，或把描写权限、停笔做法写进本产物。

背景与规则：
- 5：核心内核是一句删掉体验就不成立的前提，后续能引用。
- 3：找到前提，但过宽，或作用方式在复读内核。
- 1：百科，或与体验无关。
```

## examples

```examples
好：
- 体验内核：「反复感到垄断生存资源的掌控；对方因资源断供而让步或反抗时兑现。」发生方式与这句话同义，省略。
- 核心内核：「物资只从用户控制的仓库流出。」作用方式一句：「拒绝供货会在下一顿改变对方的选择。」不写仓库在哪条街。
- 体验锚定：站位「完全代入」；核心感觉「断供时的掌控」；轮转停点「对方让步或反抗后等用户决定供不供」。

缺料时：
- 站位、核心感觉、轮转停点缺一件 → 回复里只问这一件，产物里该项写「未定」或先不落盘。
- 用户只给了题材词 → 不编体验，gap 问他要反复感到的那一种。

偏了就改回：
- 体验内核、发生方式、角色人文、描写焦点四段同一句掌控感 → 留体验内核，其余省略。
- 核心内核写成古武阶梯、五阶段链或十阶价目 → 收成一句前提。阶梯和价目留给拓扑图谱，因果留给世界法则。
- 描写焦点写成一段感官范文 → 改成「注意力放在让步或反抗的那一刻」。
- 用「核心体验 / 描写信号」当键，或在本步写描写权限表 → 体验留在本产物，权限改写入故事推进与交互范式。
```
